Bangumi 授权

这一步只做一次。完成后，追番列表里每部番剧的详情页都能直接改状态、进度、评分和短评， 点同步就写回 Bangumi，不用再打开它的网站。

拿到了授权码

复制下面这串，去 Actions 跑一次 Bangumi Auth，粘进 code 输入框。

打开 Bangumi Auth workflow ↗

授权码只能用一次，几分钟内失效。跑完 workflow 后这串就没用了。

1在 Bangumi 建一个应用

打开 bgm.tv/dev/app （国内打不开就用镜像 bangumi.vip/dev/app， 需要过人机验证），点「创建应用」，只填两项：

  • 应用名：随便，比如 BrightCup 追番
  • 回调地址：https://brightcup.github.io/bangumi-auth/

创建完会拿到 App ID 和 App Secret，下面要用。

2把三个值填进仓库 Secrets

到 Settings → Secrets and variables → Actions 新建三个 secret：

  • BGM_CLIENT_ID = 上面的 App ID
  • BGM_CLIENT_SECRET = 上面的 App Secret
  • BGM_KEY = 下面生成的加密密钥（用来加密保管 token，别丢了，丢了要重新授权）
—

3授权一次

点下面的按钮去 Bangumi 授权（登录后会自动跳回本页，并把 code 显示在最上面）。 打不开主站就用镜像那条。

用 bgm.tv 授权 用 bangumi.vip 镜像

授权页要的是「读+写收藏」的权限；本页只负责把 code 转给 Actions，token 不会经过浏览器。

4最后一步：配 GitHub 令牌

回到任意一部番剧的详情页，点「同步设置」，填一个只能访问本仓库的 fine-grained token （权限只要 Contents: Read and write 与 Actions: Read and write）。 它只存在你自己的浏览器里，用来把改动排进队列。
